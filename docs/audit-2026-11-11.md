# Audit 2026-11-11 (Claude) - main at da5bcea

Owner request: audit the app and fix what is clearly wrong. Method: targeted scans of main for defect classes that tests and builds do
not catch, fixing only contained defects on branch `audit/2026-11-11`. Muse/King and the redesign crew are working in parallel, so
nothing here restyles a screen or moves a block. This is NOT a visual audit: the build sandbox cannot open the live app, so what a
screen LOOKS like was not judged.

## Fixed in this PR
1. **Evening entries were dated tomorrow.** "Today" came from the UTC date (`new Date().toISOString().slice(0, 10)`) in 13 places. After
   7 PM Eastern (8 PM in summer) that is already the next day. Affected: an expense Abel logs without a date; a maintenance schedule
   marked done; a checklist item marked checked; the pay-pin date; Abel's dated load notes; the Truck Fund entry date and account
   snapshot date defaults; maintenance due/overdue ("today" in the outlook, the watcher and the schedule list); the Game Plan's as-of
   date; and the Game Plan's "re-gamed today" counters (which reset at 7 PM Eastern instead of midnight). All now use the Eastern day.
   A scan test keeps the pattern out. An existing test asserted the UTC date and failed when run in the evening - live proof; corrected.
2. **Two tenant-safety gaps in the database** (the tenant-FK suite has failed on main since they landed):
   `research_learning_topics.research_run_id` (00084) and `duty_log_edits.duty_log_id` (00088) were simple foreign keys. New migration
   **00090** converts both to the composite `(company_id, fk)` form, with the same pre-flight as 00070. Defense in depth, not a live leak.
   **00090 is NOT applied; the number is the next free one on main - renumber if another branch has claimed it.**
3. **The RLS isolation suite failed on main** for `research_learning_topics`. Not an isolation hole: its insert policy also fences the
   row's shape, and the suite did not know that. The table is now listed as shaped. Scratch replay of all 79 migrations: tenant-FK 71
   composite / 8 of 8 refusals, RLS 76 of 76 tables, anon grants 0.
