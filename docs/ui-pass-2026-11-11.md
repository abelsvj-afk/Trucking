# UI pass 2026-11-11 (Claude) - seen at phone width, then fixed

Owner order 2026-11-11: "just fix my app ... label your commits so that Muse will know the work that you've done."
Branch `fix/ui-pass-2026-11-11`, stacked on `audit/2026-11-11` (PR #55). **Merged to main 2026-11-11 (`3acae01`). Not deployed. No migration in this pass.**

## How it was seen
The real app (`next dev`) was opened in a headless phone browser (390 x 844, dark, America/New_York) against a scratch Postgres
loaded with all migrations and a **fictional** company (one truck, one trailer, four loads, duty log, expenses, fuel, an advance).
A small stand-in for the Supabase API served that database. The harness lives outside the repo; no screenshot is committed.
Limits: map tiles, the realtime socket and the mail servers are unreachable from that sandbox, so the map canvas, live updates and a
connected inbox were **not** seen. Nothing here was checked against production.

## Fixed (each was visible on screen)
1. **Every page was thrown away and rebuilt on load.** The Abel drop read the viewport, clock and saved dock side during its first
   render, so server HTML never matched and React discarded the whole tree (hydration failure on all 20 pages opened). It now renders
   in the browser only; the theme attribute on `<html>` is marked as expected. Result: zero hydration errors on every page re-opened.
2. **Loads scrolled sideways.** The five-status filter was wider than the phone and dragged the page with it. Filter tracks now scroll
   inside themselves (applies to every `role="group"` filter).
3. **Company inbox and Memories ran off the right edge.** Each page nested a second `<main>` inside the layout's, doubling the padding.
   The inbox filters are now one labelled, full-width control per row.
4. **Fleet / Money / More hubs showed a card inside a card,** with the chevron dropped onto its own line. One card per row, chevron at
   the right edge.
5. **Load page:** "80.00 mi / 1100.00 mi" now reads "80 mi / 1,100 mi"; a load with no rate typed says "Not entered" instead of
   "$0.00" and "$0.00/mi" (Loads list too); the detention stamps were a pill track cut off mid-word ("Stamp do") and are now four
   full-size buttons under the stop picker.
6. **Add load was 20 fields in one column.** The everyday fields (lane, dates, rate, miles, status, truck, trailer, driver) stay on
   the page; appointment windows + detention terms and broker / customer / places fold behind two labelled rows. Nothing was removed.
7. **Raw dates.** Financial summary showed "2026-11-01 - 2026-11-30 (America/New_York)", Driver pay and Paychecks showed
   "2026-11-13". All now read as days ("Nov 1, 2026", "Fri, Nov 13").
8. **Day log entry buttons** (Fix / History / Delete) overflowed the card by a few pixels; the row now wraps. No other change to the
   day-log editor.
9. **Smart Path** said its one-line purpose twice; the second copy is gone and it says "Abel", not "the bot".

Test: `tests/unit/ui-pass-2026-11-11.test.tsx` (7 tests, one per defect class).
