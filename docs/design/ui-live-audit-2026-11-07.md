## 7. Home map - what is visibly broken now (not redesigned)
I cannot screenshot your live phone, and the build sandbox cannot load map tiles, so this list is what the code makes visible, not a photo audit. Tell me which of these you see and which I missed.
1. **The map card simply is not there** whenever there is no fresh GPS fix and Telegram has none newer than 3 minutes (permission off, GPS warming up, just reopened). By design it never shows a blank map, but it also gives no reason, so it reads as missing. Proposed (small, not a redesign): a one-line "Map off - no fresh location" with the existing Location prompt link.
2. **It sits inside the generic padded white card** (every `<section>` is one), so the map is inset by 1.25 rem with a rounded card around it rather than edge to edge. Cosmetic.
3. **Tiles come from tile.openstreetmap.org**, whose usage policy discourages app-scale use; if tiles ever fail you get an empty grey card with the truck marker. No fallback or "tiles unavailable" message exists.
4. **Poor-accuracy fixes (>50 m) draw a grey marker** with no legend explaining grey.
5. **Larger scope question for you (not built):** do you want Home's map to stay a glance card, or become the primary Home surface (full width, route + next stop + ETA overlay)? That is a redesign and your call.

## Abel was down: 131 tools offered, the API limit is 128 (root cause, fixed)
Every Abel message failed because each request carried the whole tool registry (131 after the email and payday tools; 130 before) and the model API rejects more than 128. Fix: `services/bot/tool-budget.ts` - each turn offers all write tools plus the read tools that match what was said, capped at 120; the full registry is unchanged (writes still execute from it after a yes). A last-resort trim in the OpenAI provider logs loudly instead of failing every message. Tests pin: the registry is over the limit, every selection is under it, writes are always offered, the matching reads are kept, no duplicate tool names. **This needs a deploy to take effect.**
